# 工程新建（裝修）規格需求表 — Demo 示範版

> **所有資料皆為虛構範例。** 人名、分機、成本代碼、EIP 單號與案件內容都是示範用，不代表任何真實案件。

## 用途

院內要裝修、改空間或加設備時，使用單位用這張線上表單把需求告訴工務處；系統依程序書規則即時預判後續流程（工程類別、是否送院區規劃管理中心審核、法規、感控、職安、合約、進度表、驗收簽核流程）。本頁是給主管與同仁試用的 Demo 版，不需要匯入檔案就能切換任一角色、載入任一流程站點。

單檔離線網頁（`index.html`），不連任何後端；草稿只存在瀏覽器本機（與正式版分開儲存）。

## 三個角色

| 角色 | 做什麼 |
|---|---|
| 使用單位 | 一步一題白話填寫需求，主管簽名後下載案件檔、產生 EIP 6.1 填寫內容 |
| 工務處 | 會勘、費用初估、確認系統預標的工程類別／送審／法規／感控／職安 |
| PCM（專案管理單位） | 設計確認、標單與合約、驗收會驗與簽核流程規劃 |

## Demo 導覽（建議順序）

1. **以使用單位身分填**：控制列按「(a) 空白開始」，照 8 個步驟回答，看「接下來會怎麼走」即時預判。
2. **切工務處看預標**：按「(c) 工務處已判定」（6F 透析室擴充 4 床案，初估 160 萬），看系統自動預標。
3. **切 PCM 看驗收流程**：按「(d) 標單完成」（決標 148 萬），看驗收簽核鏈與交接紀錄；再按「對照：小案約 20 萬」比較小型案件路徑。
4. **列印紙本**：按頁首「列印」，看三方合一紙本（可另存 PDF）。

隨時可按「重置 Demo」清空。

## 情境一覽

| 情境 | 角色／站點 | 系統預判重點 |
|---|---|---|
| (a) 空白開始 | 使用單位／F1 | — |
| (b) 已送出・待會勘 | 工務處／F2 | 中型；送審待判定（預算級距跨 200 萬）；合約需要；驗收 ≧100 萬鏈 |
| (c) 工務處已判定 | 工務處／F3 | 中型；送院區規劃管理中心（委外設計）；合約、進度表、感控、職安需要 |
| (d) 標單完成 | PCM／F6 | 決標 148 萬；驗收 ≧100 萬鏈；交接紀錄 14 筆 |
| 對照：小案約 20 萬 | PCM／F6 | 小型營繕；免送審、免合約、免進度表；驗收 8–20 萬鏈 |
